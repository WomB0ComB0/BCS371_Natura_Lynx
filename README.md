# Natura Lynx

Natura Lynx is a user-friendly mobile app that combines real-time plant identification with engaging educational content. Designed for families, educators, and beginners in botany, the app simplifies nature exploration and learning.

---

## Features

- **Plant Identification**: Use your camera or photo gallery to identify plants instantly.
- **Learn Section**: Access a database of plants with detailed information and search functionality.
- **NatureAI**: Discover interesting facts about plants through AI-generated content.
- **User Profiles**: Track your stats and manage your account.

---

## Getting Started

### Prerequisites
- A mobile device with a camera.
- Internet connection for API-based plant identification and NatureAI features.

### Installation
1. Clone this repository to your local machine.
2. Open the app and sign up to create your profile.
3. Start identifying plants or explore the Learn section.

---

## Screens and Navigation

### Home Screen
- Navigate to **Identify Plants**, **Learn Section**, or view stats.

### Identify Screen
- Use the **Take Photo** button to capture a new image or select an existing one from the gallery.

### Learn Screen
- Search for plants by name or browse categories to learn about local flora.

### NatureAI
- Generate fun and educational facts about plant species using AI.

### Profile Screen
- View your stats and log out when needed.
